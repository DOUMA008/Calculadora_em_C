## Nome do aluno: Vítor Hugo Nunes Pereira.

## Objetivo

O objetivo deste trabalho é criar uma calculadora utilizando o Flowgorithm, colocando em prática os conceitos de lógica de programação aprendidos na matéria de Desenvolvimento de Algoritmo e Pensamento Computacional.

O programa possui 20 opções de cálculos diferentes. O usuário escolhe uma opção no menu, digita os valores pedidos pelo programa e depois recebe o resultado.

Entre as opções estão os cálculos obrigatórios de **IMC** e **área de figuras geométricas**.

## Como o programa funciona

Quando o programa começa, aparece um menu com as opções de cálculo.

O usuário deve escolher uma opção digitando o número correspondente. Depois disso, o programa pede os valores necessários para fazer o cálculo.

Após colocar os valores, o programa faz a conta e mostra o resultado.

## Cálculo do IMC

O IMC é calculado usando o peso e a altura da pessoa.

A fórmula utilizada é:

```text
IMC = peso / (altura * altura)
```

O usuário informa o peso em kg e a altura em metros, e o programa calcula o IMC.

## Cálculo de áreas

O programa possui algumas opções para calcular áreas de figuras geométricas.

### Área do retângulo

```text
Área = base * altura
```

### Área do triângulo

```text
Área = (base * altura) / 2
```

### Área do círculo

```text
Área = 3.14159 * raio * raio
```

## Como executar

Para executar o programa é necessário ter o **Flowgorithm** instalado.

Depois:

1. Abrir o arquivo `calculadora.fprg`;
2. Executar o fluxograma;
3. Escolher uma opção do menu;
4. Digitar os valores solicitados;
5. Ver o resultado na tela.
