# Calculadora_em_C

Projeto: Calculadora simples em C/C++ com operações básicas: adição, subtração, multiplicação, divisão e porcentagem.

Arquivo principal: `calculadora.cpp`

Como compilar:

- Usando g++ (recomendado para arquivos .cpp):

  g++ calculadora.cpp -o calculadora

- Ou usando gcc (se preferir compilar como C):

  gcc calculadora.cpp -o calculadora

Como executar:

  ./calculadora

Uso:

1. Execute o programa.
2. Escolha uma opção (1-5) para a operação desejada.
3. Insira os números conforme solicitado.

Observações:

- A divisão por zero é verificada e retorna uma mensagem de erro se ocorrer.
- O programa lê números de ponto flutuante (float) e mostra o resultado com duas casas decimais.
